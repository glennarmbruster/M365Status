How Live Status Sync Works

Zero-backend architecture for GitHub Pages

1. Automatic Live Browser Feed (Active Now)

This page automatically fetches live Microsoft 365 component statuses and active incidents directly from the open, CORS-enabled MicrosoftRadar Statuspage v2 JSON API (microsoftradar.com/scope/microsoft-365/api/v2/summary.json) every 60 seconds—no API key or backend required.

2. Optional: Custom ./status.json via GitHub Actions

Before querying the public API, this page checks for a local ./status.json file in your repository. If you ever want to mirror status data directly into your GitHub repo on a schedule, add .github/workflows/sync-status.yml: 

name: Sync M365 Status
on:
  schedule:
    - cron: '*/10 * * * *'
  workflow_dispatch:
permissions:
  contents: write
jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Fetch Live M365 Status JSON
        run: curl -sL "https://microsoftradar.com/scope/microsoft-365/api/v2/summary.json" -o status.json
      - name: Commit Updated Status
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add status.json
          git diff --staged --quiet || git commit -m "chore: update M365 status"
          git push

Self-Help Troubleshooting

If status is green above, try these quick steps

1. Test in an Incognito / Private Browser
Stale browser cookies often cause login loops or blank pages. Open a Private/Incognito window and sign in at m365.cloud.microsoft to verify if the issue is local to your browser cache.
2. Check Corporate VPN or Wi-Fi Portal
VPN disconnects or hotel/public Wi-Fi captive portals can block Teams calls and OneDrive sync while regular websites still load. Disconnect and reconnect your VPN or test on a mobile hotspot.
3. Desktop App vs. Web App Check
If desktop Outlook or Teams freezes, right-click the app icon in your system tray/dock, select Quit (not just closing the window), and use the web links above while it restarts.
4. When to Contact IT Helpdesk
If all M365 services show Available above and incognito mode still shows an error code (such as AADSTS or license expired), screenshot the error message and share it with your IT Helpdesk.
